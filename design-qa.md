- Содержание: порядок экспорта совпадает с макетом — Jira (отправить, копировать), Файлы (.report, Excel), Другое (HTML), два разделителя. Report/Capture — переключатель приложений. Импорт возвращён отдельной кнопкой по уточнению пользователя.
- Приоритетных визуальных проблем P0/P1/P2 в итоговом хедере не осталось.

Допустимые продуктовые отличия: отдельная кнопка импорта и центрирование добавлены по последующим указаниям пользователя. Кнопки установки/обновления появляются только при доступности соответствующего действия. Существующие настройки чек-листа и корпоративная схема Jira сохранены; сообщение о неподключённой Jira использует имеющийся диалог подтверждения приложения.
